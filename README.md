# 🎡 Ruleta

Ruleta online con animación fluida, sonido, historial de resultados y paletas de colores.

## Uso

Tocá la ruleta para girar. Podés editar las entradas (una por línea) en el panel de la derecha, mezclarlas u ordenarlas, y cambiar el sonido, la duración del giro y los colores en la pestaña **Ajustes**.

## Publicar con GitHub Pages

1. Creá un repositorio nuevo en GitHub (por ejemplo `ruleta`).
2. Subí los archivos de esta carpeta (`index.html`, `README.md` y `.nojekyll`).
3. Entrá a **Settings → Pages**.
4. En **Source** elegí **Deploy from a branch**, rama `main` y carpeta `/ (root)`. Guardá.
5. Esperá un minuto y tu ruleta va a estar en `https://TU-USUARIO.github.io/ruleta/`.

No necesita instalar nada: es un único archivo HTML.
